# FPS Shooter — Learning Project  
**Первый пет-проект в жанре шутера от первого лица, созданный в рамках изучения Unity и C#.**

---

## 🇬🇧 English

### About
This is a **personal learning project** — a first-person shooter (FPS) built to practice core game development concepts in Unity.  
The goal was to implement player movement, shooting mechanics, enemy AI, and basic animation systems from scratch.

### Tech Stack
- **Engine**: Unity (URP)
- **Language**: C#
- **Tools**: Unity Animator, NavMesh, Input System, Cinemachine

### Features
- Custom player controller (movement, jumping, mouse look)
- Weapon system with raycast-based shooting
- Enemy AI with patrol and chase states
- **All animations created manually** using Unity Animator
- Health system and simple UI

### Assets
- Core logic and systems: **written from scratch**
- Some 3D models and textures: **imported from free asset packs** (for learning purposes only)
- No paid assets used

> 🔧 **Note**: Large asset files (e.g., `.fbx`, `.psd`) are excluded from this repository to comply with GitHub limits. The project is fully functional with lightweight placeholders.

## 🇷🇺 Русский

### О проекте
Это **обучающий пет-проект** — шутер от первого лица, созданный для освоения основ разработки игр в Unity.  
Цель — реализовать с нуля систему передвижения, стрельбы, ИИ противников и анимации.

### Технологии
- **Движок**: Unity (URP)
- **Язык**: C#
- **Инструменты**: Unity Animator, NavMesh, Input System, Cinemachine

### Возможности
- Управление игроком (ходьба, прыжки, поворот за мышью)
- Система оружия на основе рейкастов
- ИИ врагов с режимами патрулирования и преследования
- **Все анимации сделаны мной вручную** через Unity Animator
- Система здоровья и простой UI

### Ассеты
- Логика и скрипты: **написаны с нуля**
- Часть 3D-моделей и текстур: **импортирована из бесплатных ассетов** (исключительно для обучения)
- Платные ассеты **не использовались**


> 🔧 **Примечание**: Крупные файлы (например, `.fbx`, `.psd`) исключены из репозитория из-за ограничений GitHub. Проект остаётся полностью рабочим — тяжёлые ассеты заменены на лёгкие заглушки.
